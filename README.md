1. Установить Python3.12:

- https://www.python.org/ftp/python/3.12.0/python-3.12.0a2-amd64.exe

2. Установить Pip:

- Скачайте установочный скрипт get-pip.py. В любом случае щелкайте правой кнопкой мыши на ссылке и нажмите “Сохранить как…” и сохраните скрипт в любую безопасную папку, например в “Загрузки”.
- Откройте командную строку и перейдите к каталогу с файлом get-pip.py.
- Запустите следующую команду: python get-pip.py

3. Скачать репозиторий и установить все зависимости проекта:

- Нажмите на зеленую кнопку "Code" и скачать zip архив, затем распаковать его и перейти в распакованный каталог
- Откройте этот каталог в терминале, например "PowerShell", и введите команду `pip install -r requirements.txt`

4. Запускаем код:

- Зайдите в каталог проекта в терминале и введите команду `python main.py`
